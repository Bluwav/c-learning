# 字符串和格式化输入输出

## 示例

用数组存储字符串

```C
#include<stdio.h>
#include<string.h>
#define DENSITY 62.4
int main()
{
    float weight, volume;
    int size, letters;
    char name[40];

    printf("Hi!What's your first name?\n")
    scanf("%s",name);
    printf("What's your weight in pounds?\n);
    scanf("%f",&weight);
    size = sizeof(name);
    letters = strlen(name);
    volume = weight/DENSITY;
    printf("Well, %s, your volume is %2.2f cubic feet.\n",name, volume);
    printf("Also, your first name has %d letters,\n",letters);
    printf("and we have %d bytes to store it.\n",size);

    return 0;
}
```

## 字符串

用双引号括起来，但`""`不是字符串的一部分。

### char类型数组

- 数组是同类型数据元素的有序序列，由连续的存储单元组成，每个单元存储一个字符。

- 字符串末尾一定是空字符（null），占数组中的一个单元。

- `char name[40]` 中方括号表明这是一个数组，40表明元素数量，char表明元素类型。
  由于空字符占一位，实际上只能存储39个字符

### 使用字符串

- 编译器会在字符串末尾加上空字符。

- `scanf()`只会读取字符串中的第一个单词，在遇到第一个空白（空格、制表符、换行符）时不再读取输入。

- `"x"`与`'x'`的区别：前者是派生类型，且实际上是两个字符，后者是基础类型（char）。

### sizeof（搭配%zd返回类型）是C的内置运算符。

- 以字节为单位给出制定类型的大小。

` printf("%zd", sizeof name);`

### strlen函数

- 给出字符串的字符长度，空字符不计入。（sizeof计入）
