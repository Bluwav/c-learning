# C语言概述


### 一、示例
```c
#include<stdio.h>
int main(void)
{
    int num;
    num = 1;

    printf("I am a simple computer.\n");

    return 0;
}
```


- #include指令和头文件
`#include<stdio.h>`相当于把`stdio.h`文件（标准输入/输出头文件）内容复制粘贴，是一条C预处理器指令。

- `main()`函数，函数是C程序的基本模块，圆括号中包含返回值的类型。
调用函数`printf()`执行结束后回到主调函数。

- 注释 `/* 这是一条注释 */`。

- 花括号 `{ }` 把函数括起来

- 声明是C的重要特性。例如 `int num;` 把特定标识符和计算机内存中的特定位置联系起来，同时也确定了存储在某位置的信息类型或数据类型。分号是声明的一部分。

（命名：不能以数字开头）

- 赋值。

- 实际参数与形式参数。实参是传递给函数的特定值，形参是用于存储值的变量。

- `return`语句，返回值。

### 二、简单程序结构

- 函数头
`int main(void)`

- 函数体：声明，语句
```c
{
  int q;
  q = 1;
  printf("%d",q);

  return 0;
}
```

### 三、进阶

- 多个函数
何时执行某函数取决于其在`main()`函数中被调用的位置,而不是定义在文件中的位置。

- 调试程序，检查语法错误和语义错误。
